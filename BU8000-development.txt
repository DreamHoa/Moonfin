Removed the unbounded outer per-cue retry added in the previous customization. The existing three-attempt request budget and body timeout remain; a persistently unavailable cue may be skipped so later subtitles can continue.
Regression validation: two new tests failed before the fix; four related suites and 74 tests pass after it. Full build lint and production compilation passed.
Signed build 20261114.3-cache was installed in place, retained the session, and all 130 top-level JavaScript files matched the signed package. PGS canvas samples contained changing subtitle images during playback and after forward/backward seeks using Moonfin's own AVPlay seek wrapper.
Observed first pixels after seek initiation: +10 seconds 6.314s (seek callback 5.229s), +600 seconds 7.067s (callback 2.829s), -600 seconds 12.679s (callback 2.897s). These times include native seeking and dialogue gaps; they do not isolate subtitle fetch latency. This is bounded sample validation, not proof that all intermittent omissions are eliminated. Large backward seeks still have a visible wait.
